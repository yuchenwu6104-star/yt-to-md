# 自寫文章的個性與語調

本檔只用於 `_fb_` 或能確認是作者自寫、且允許恢復個人聲音的文字。不得套用到受逐字稿約束的 `_yt_` 引述。

## 保留什麼

- 作者明確的觀點、偏好、猶豫、幽默與不耐煩。
- 長短句交替、自然停頓，以及少量有意義的口語。
- 真實經驗中的具體細節與不完美，不要磨成中性的說明文。

## 刪除什麼

- 每段相同節奏、每個觀點都先預告再解釋的模板。
- 為顯得完整而補上的空泛結論、三點式清單與平衡句。
- 沒有來源的戲劇化比喻、假想動機與替作者新增的立場。

## 改寫方法

1. 找出文章最像作者本人說話的兩至三段，作為語調基準。
2. 先保留觀點與具體細節，再調整句序與節奏。
3. 允許直接、帶立場的句子；不要把每句都改成客觀報告語氣。
4. 朗讀全文，刪掉只負責「顯得會寫」而不提供內容的句子。
5. 若原文平淡，不可憑空發明人格；自然清楚即可。
