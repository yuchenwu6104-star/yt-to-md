## 讀這份範本時要注意的九件事

1. **引述是主體，不是點綴。** 整篇幾乎每一段都由「」承載。串接句只回答「誰、對誰、在什麼脈絡下說」，然後就讓路。
2. **對話保留成對話。** 主持人的提問與回答同樣是引述，不壓成「主持人問到 X，他回答……」。一問一答的張力來自兩個人的原話並排。
3. **翻譯是白話，不是書面語。** 「市場百分之百認為他們現在賺得太多」不是「市場認定公司的獲利高峰難以持續」；「狠得不得了」不是「工作極為勤奮」；「毒品市場」不改成「需求極度旺盛的市場」。
4. **具體名字、例子、比喻一個都不丟。** Dwarkesh、TBU、Eric Vishria、Michael Mauboussin、Dylan Patel、a16z、Iconiq、ASCO、卜派菠菜、螺旋槳與噴射引擎、暗物質、聖杯，這些是內容，不是裝飾。
5. **講者沒講完的句子可以留著。**「他們早就... 」照原樣，不要替他補完。
6. **不解釋術語。** router、flops、prefill、decode、neocloud、承購協議、帕累托前沿直接用，不加註解、不加括號說明。
7. **小標少而短，只當路標。** 「舊 GPU 2026 年還在漲價」「信貸是唯一站得住腳的利空」「中國的 DUV」。不用小標預告內容或下結論。有些段落根本沒有小標。
8. **零編者按語。** 沒有一句「這是講者的假設，不是公司財測」「不代表每個專案都會如此」。查證痕跡完全不在正文裡。
9. **引導動詞極簡。** 幾乎只有「說」「問」「回答」「補充」。不追求動詞變化。

Gavin Baker：「我覺得七月像是一個月就走完 2022。」
他問 Patrick：「你在這裡待了一個夏天，有沒有聽過任何一個關於 AI 的負面量化指標？有沒有任何一個減速的例子？」Patrick 回答：「完全沒有。事實上每一個指標都在加速。」
Baker 說：「不管你怎麼切都一樣。GPU 的可用性、GPU 的租賃價格、這個月 DRAM 的現貨價、token 的成長，每一項都在加速。」
唯一被端出來的負面數據點，是第三方資料顯示 Anthropic 的成長曲線稍微偏離了原本的軌跡。Baker 認為那有可能是真的，但同一時間 OpenAI 和開源都在大幅加速，加總起來是淨加速。而且這個數據點本身就有爭議：「Anthropic 的股東們很想跳出來說這不是真的，可是他們也很怕如果被公司知道是他們說的，IPO 就分不到額度。」
股價的位置與這些數字對不上。Baker 說：「輝達現在的預估本益比是過去十年最低。半導體只有在解放日和 DeepSeek 那兩次大特價，且那兩次都是 V 型底。」Patrick 問這對他代表什麼，他說：「市場百分之百認為他們現在賺得太多。我們必須謙虛，也許真的是這樣。」

----

Baker：「市場對 Anthropic 和 OpenAI 沒有能見度，對這些在美國把推論變現的開源推論雲也沒有，Fireworks、Baseten、Modal、Together。你把這幾家都看進去，畫面會完全不一樣。」開源這一季的加速來自 GLM 5.2 和 Kimi K3，還有輝達的 Nemotron 持續往前推；Anthropic 則幾乎確定在產出可觀的自由現金流。
Baker 說：「大家都在看那張半導體現金流往上、超大規模雲自由現金流往下的圖，可是那張圖漏掉了這些私人公司。」他把開源比喻成暗物質：「開源有點像公開市場的暗物質，公開市場很難估量到它。」
量不到不代表看不到方向。他說：「你只要追蹤這些推論雲在講什麼，這些是人在 Podcast 上講的、在會議裡講的，不是經過查核的財報，但需求明顯在加速。這些商業模式最驚人的地方是，它們成長的速度幾乎跟前沿實驗室早期一樣快，可是燒的現金很少。」

----

舊 GPU 2026 年還在漲價

Baker：「2024 或 2025 年，應該沒人想過，這些舊 GPU 的價格到 2026 年還能垂直往上。」當時看多的人以為 GPU 租金會緩慢下滑，看空的人以為會斷崖式下滑，於是大家都想搶簽長約，很多 neocloud 業者也非簽不可，因為要有承購協議才能把 GPU 融資出來。結果是已經裝機的算力被鎖在遠低於現貨的價格上。Baker 說：「隨著這些合約到期，算力會用更高的價格重新定價。現貨就算跌，算力還是會被重新定價到更高。」
他剛遇到一個例子：「我今天早上才跟一家公司談過，是那種大家都想跟他們做生意的新創。他們租了幾千張 Blackwell，價格大概在每 GPU 小時兩塊多。同樣一個叢集，一樣的規模，一樣是 B200，每個地方都一模一樣，七個月後他們希望能用四塊租到。」
另一個例子來自公開發言：「其中一家推論雲在 Podcast 上說，合約到期的時候他們準備為 Blackwell 多付一倍的錢。這等於是說，所有的超大規模雲現在都賺得太少。」
Baker 問 Patrick 有沒有聽過任何人說自己 GPU 太多。Patrick 說：「一個都沒有。實際上是相反，聽起來像毒品市場。」
七月市場對 Meta 出租算力的解讀，恰好證明了同一件事被讀反了。Baker 說：「市場以為 Meta 有多餘的算力、要砍資本支出，這是災難。完全不是那麼一回事。他們是看到 SpaceX 把一批訓練用的大叢集賣進市場，價格相對那些合約價有非常巨大的溢價，他們看到機會了。」然後 Meta 後來公布的財報也沒有砍資本支出。
現金流已經開始反映這件事。Baker 說：「微軟、Meta 和亞馬遜的營運現金流從 28 加速到 32。這一季有異常多的一次性項目，扣掉之後是從 28 到 35。在這個規模上，這是很實質的加速。」他強調時間點：「而且這還是在 Rubin 之前，Rubin 還會帶著可觀的溢價；也還在這些合約重新定價之前。」他另外提到，微軟六月上線了一大批，第二季根本還沒反映進去。

----

信貸是唯一站得住腳的利空

Baker 承認：「實質利率上升，這說得通，我們投了這麼多錢。信貸的比重確實在增加，即使絕大多數還是靠營運現金流支應。實質利率上去，利差擴大。Meta 上週發債，價格沒有發在你以為 Meta 該有的位置。」「CDS 上升、利差擴大、實質利率上升，這些都是無法否認的事實。如果我們需要債來完成這一輪，那真的會非常可怕。」
Patrick：「這就是典型的資本循環，我們開始用債務把自己撐得太開，就是從這裡開始出問題。」Baker 同意：「債務推動的建設會要求立刻還款。所以供需只要稍微失衡，事情可以崩得非常快。網路泡沫就是這樣。」
他反駁這個利空的方式，是重新定價。市場對超大規模雲的共識預估裡藏著一個假設：「你看那些 Blackwell 和 Rubin 的 gigawatt，卻粗魯地被用 Ampere 的水準去變現。還不是 Hopper 喔，是 Ampere。」「那樣算的話是 1.3 到 1.4 兆的營運現金流。退一步假設他們用比現在的 Blackwell 稍低的水準變現，就會變成兩兆左右，等於把 7,000 億的信貸需求拿掉了。」現金流越好，信貸比率越好看，反過來又讓舉債變得更容易。
Patrick 問他什麼情況會改變看法。Baker 說：「就是營運現金流這件事沒有發生，所以我們只好舉債。」他補充另外兩個訊號：「如果 GPU 價格出現相當劇烈而且持續的收縮，市場會立刻反應，那會很讓人擔心。如果 GPU 開始變得很容易拿到，也是。」他也提到兩集前談過的 Blackwell 空窗期：那些晶片初期主要拿去訓練，而訓練不產生回報，市場在四月、五月、六月選擇不計較這段空窗期，七月突然又開始計較了，但偏偏那正是營運現金流開始加速的時候。

----

七月的另一個賣壓來自開源。Kimi K3 發布之後，Silicon Data 的 token 指數走平，兩件事被連在一起解讀成利空。昂貴的前沿 token 轉向開源 token。
他認為市場讀反了，錢只是在層與層之間移動：「開源拿走市佔，做的事情是把毛利從前沿模型那一層抽走。因為有需求彈性，反而把 token 的整體需求推上去。Anthropic 和開源都跑在同一批雲上，這些雲收取的算力費用是一樣的。所以你只是把毛利從前沿模型那裡拿走，毛利實際上轉而推進 AI 基礎設施那一層。」
他還提出一個旁證：「如果開源對他們的生意不好，Jensen 又是全世界最大的開源支持者，這說得通嗎？」至於為什麼開源重要，Baker 說：「倘若世界上只有一兩個前沿模型主宰、收 90% 的毛利，那對人類不好，對社會可能也不好。」
同一個機制在企業端的案例是 router 。Baker 說：「你可以拿自己的資料客製一個開源模型，放在一個 router 裡面。router 先跑你自己的模型，再讓 Claude 或 Grok 這類前沿模型檢查一遍。很多情況下你能用一半的成本拿到稍微更好的結果。」省下來的錢從哪裡來，他說：「你是把 token 從毛利率 90% 的那一種，換成毛利率大概 30% 的那一種，省的錢就是從這裡來的。可是這些 token 耗費的算力是同源的。」
實際發生的順序是這樣：「這些大型上市公司都在說，我的 AI 支出翻了 20 倍，三個月就把預算燒完了。所以他們架了一個 router，支出真的降下來，但他們產生的 token 數量可能反而增加。」帳單持平甚至下降，消耗的 GPU / hr 卻往上。

----

如果開源模型愈來愈好，前沿模型的經濟價值會被侵蝕嗎？Baker 認為正好相反。
Patrick 提到一份 Cursor 的研究：「Cursor 那件事我很有興趣，感覺像 AI 在快速重跑一遍人類已經學會的東西：用前沿模型規劃，再把任務發包給比較笨的模型，效率高了 15 倍。」Baker 順著推：「今天如果你有一堆 120 IQ 的開源模型，跑起來又很便宜，那一個能指揮它們的 160 IQ 模型，不是變得更有價值嗎？」Patrick 用薪酬結構做類比，問這是不是就像執行長的薪水是中位數員工的幾倍，Baker ：100%。
他也提出反面看法：「有些朋友認為，前沿模型一旦達到遞迴自我改進，靠蒸餾就能在每一個智能水準上把服務成本壓得低很多，開源就沒有地方站了。那是 Anthropic、OpenAI、Grok 極大化派的看法。任何事情都有可能，我們要非常謙虛，我這個月之後變得特別謙虛。但那看起來應該不是這樣。」
理由是資料的所有權已經轉移了：「因為有非常多 AI 原生公司已經累積了相當數量、屬於自己領域的專有資料。在開源和這些推論雲、路由器成熟之前，你根本沒得選，服務條款寫什麼你就接受什麼。現在可以了，這給你一定程度的獨立性，也許還有耐久性和安全感。」
工具端也已經備好。Baker 說 Fireworks 推出的 Nexus，對在用 Claude Code、OpenAI Codex 或 Grok build 的人來說「真的就是三行程式碼、20 個字」，Fireworks 把資料吃進去、幫模型做強化學習，再由 router 送出查詢。Harvey 在被收購前、Cursor、Lora 都往這個方向壓得很重。
這件事改變的是這類公司的體質。這一批公司過去常被當成 ChatGPT 的一種殼，成長極快卻看不出耐久性，Benchmark 合夥人 Eric Vishria 兩年前就說過，他從沒看過這麼多公司從創立到一年 5,000 萬美元營收只花九個月左右。Baker 說：「你如果能從只用一到三個前沿模型，變成前沿模型只佔你 30% 到 60% 的 token 消耗，其餘用自己的 RL 模型，你突然就不是一個外殼了，防禦力強得多。」
但他對終局的描述也沒有把前沿說死：「前沿 token 可能還是拿走絕大部分的經濟價值，只是不像過去那樣全部拿走。開源 token 可能會是被處理的 token 中的大多數。」而這對基礎設施的需求是好事，理由還是那一句：一個 token 就是一個 token，做出來要花掉一樣的 flops、瓦數、空間和散熱。

----

「現在什麼東西都缺。如果哪裡有趨緩，那只是因為我們沒辦法快點把 gigawatt 通上電。」但他認為電的問題還是會解決：「法規在往好的方向走，渦輪機廠商、柴油發電機廠商都在拉產能。你甚至把渦輪機從舊飛機上拆下來翻新再拿來用。資本主義非常非常擅長這件事。」
比較難的是記憶體。Baker 先說明它為什麼是主角：「在給定的算力下，你給每一個 flop 配的記憶體越多，吐出來的 token 就越多。這是提高單位算力 token 產出的大重點。」而更多 token 產出等於單位成本下降，所以「需求完全沒有出現負面反應，一點彈性都沒有，因為它是壓過其他所有軸的那根軸」。
但市場結構改變，也是 Baker 承認自己看錯的地方：「我們正在從短期把數字衝到最大，轉向用短期的上檔空間去換長期協議，記憶體這邊尤其明顯。形式有很多種，但基本上是客戶預付，有底價也有上限。」
長約一旦成為主軸，毀約就變成一場賽局。Baker 把玩家列出來：「規模上真正重要的就四家：亞馬遜的 Trainium、Google 的 TPU、AMD，然後是比其他所有人加起來還大很多的輝達。」再推情境：「假設是 2027 或 2028 年，你有點想毀約，想拿到更低的價格。可是我認為接下來幾年市佔率會由供應鏈配額決定。你毀了約，接下來兩三年只要籌碼因為任何理由回到記憶體那邊，你就出局了。」
供應方會怎麼回應，他說：「他們會說，好啊，你毀了價格協議，那我們就把量給你的競爭對手，然後你丟了市佔。」他說這跟過去的產業結構完全不同：蘋果是壓倒性最大的買家，想怎麼樣都可以，就算把海力士得罪得很慘，美光當然還是會接。這次不一樣。
同一根軸上還有一個很少討論到的變數。Baker 說：「整個算力的討論裡少了一塊，就是把這些不受 HBM DRAM 限制、而且常常做在比較舊的製程、不跟最新最好的 GPU 搶產能的 SRAM 加速器放進來會怎麼樣。」他描述一種理想的拆法：「拆解推論的時候大家會講 prefill 和 decode，但 decode 有兩部分，注意力和前饋網路。終極的聖杯是 prefill 在一顆可能沒有 HBM DRAM 的晶片上做，注意力在配了 HBM DRAM 的高功率晶片上做，前饋網路在其中一顆 SRAM 晶片上做。」
「前饋網路這一段你就是打不過 SRAM。不管你怎麼調晶片上算力、HBM DRAM 和 SRAM 的比例，工作負載一直在變。要是能夠拆成這三塊，我認為對 AI 的投資報酬率會非常非常正面。」

----

Baker 說目前的環境對輝達有利到讓他不太理解股價：「以現在的環境對輝達有利成這樣來說，它為什麼用這麼低的倍數在交易，我有點難理解。」
第一個優勢是融資：「如果你需要把晶片拿來融資，沒有什麼東西比輝達的 GPU 更好融資，沒有。」第二個是土地和電力的媒合，他說輝達這盤棋下得很好。第三個是新的商業模式：「他們推出了一個很聰明的新模式，我形容為一個信用外殼，外加一個在 GPU 價格高於某個底價時的營收分成。」他認為這條路的上檔可能很大：「這可能讓他們很快就靠權利金實質上擁有一門很大的雲端生意。」
他特別澄清這不是老式的供應商融資：「錢不是他們借的，是別人借給 GPU 買家的。輝達說他們在所有股權投資裡都寫明那筆錢不能用來買輝達的晶片，不過很明顯錢是可以互相替代的。」
股權這件事他認為輝達學到了教訓：「基本上每一次他們沒有拿股權，事後都證明是錯的。除了記憶體公司之外，他們幾乎什麼都拿了股權，Anthropic 也是很久之後才去拿。Jensen 看得到每一家實驗室，所有的進展他都知道，他看到的東西讓他偏向看多。」
Patrick 問他如果是 SK 海力士的執行長會怎麼做。Baker 說：「我會做輝達現在在做的事。我會去找 GPU、Trainium 這些東西的買家，跟他們說我要拷貝輝達的信用外殼。我們今天先從現金流拿出一筆錢放進去，讓那個人心裡舒服一點，但我們要在後續的營收裡分一杯羹。」他說黑石和阿波羅八成也正在向記憶體公司提某種變形版本，而這是長約的邏輯延伸，一樣拿上檔換耐久性，只是換成權利金的形式。
同一個結構對後進者是壓力。Baker 說：「那家新創在台積電付的價格比輝達高，買 HBM DRAM 的價格比較高，融資那些晶片的利率也沒辦法跟輝達一樣。用 HBM DRAM 的話，你就在這件事的正中間。」他保留的例外，是那些架構上做出完全不同選擇的公司。

需求從哪裡來，又為什麼不會停？
Baker 說他會去 X 上看反駁意見，最常見的一條是：就算接受超大規模雲只是現在賺得少、算力重新定價會讓現金流加速，但那筆現金流的來源到底在哪裡？
他說答案只有兩個來源：「照定義來說，它只能來自生產力帶來的更快經濟成長，也就是 Satya 講的那句，我們要嘛開始以 10% 成長，要嘛就沒有；或者來自勞動替代。」
勞動替代已經在發生，模式跟大家想的不太一樣：「在很多 AI 原生公司你確實看得到勞動替代，但不是因為他們在裁人，是他們不再雇那麼多人。」他說 a16z、Iconiq 這些機構做過的研究顯示，這些公司的每位員工毛利貢獻相對過去世代的新創是垂直上升的。
Patrick 問到這些公司的 token 支出佔比。Baker 說在很吃產品自然成長的公司「會到 20%、25%」，Patrick 提到 Dylan Patel 的公司是 30%，是他聽過最高的。Baker 說：「我還聽過 50%。知識工作有 25 兆美元。就用你講的 20% 好了，那就是五兆，而這五兆要嘛來自勞動替代，要嘛來自更快的經濟成長。身為人類，我們非常非常希望它來自更快的經濟成長。」
他當天早上聽到一個相反方向的訊號。一位創過好幾家公司的頂尖科技執行長跟他說，把 COVID 時期的過度招募調整掉之後，創辦人控制的公司其實沒有人真的在裁員。Baker 說：「這些人應該是最快會用 AI 來提高效率的一群，可是他們沒有在大規模裁員。這大概就說明，他們認為把人裝配上十萬美元的 token 支出，還會有很多機會。」
多頭的版本是成長。Baker 說：「你看過 Cognition、Ramp、Stripe 的圖，在 AI 上花最多錢的公司，成長明顯比較快。」
他也接受懷疑的人的質疑，說這些數據確實沒有考慮產業別。
採用的節奏在不同地方差很多。AI 原生公司壓得最重，把預算主要放進 token 而不是人；那批走在前面的上市公司可能剛架起路由器；美國東岸的公司則是幾乎還沒導入；Patrick 補充：「歐洲則是還在想怎麼監管 AI，然後才用。」而 Baker 說有個念頭他一直擺脫不掉：「全世界大概只有 50 萬人，也許 25 萬人有在用 agentic AI，而我們已經面臨嚴重的算力短缺。地球上有七、八十億人，從 50 萬變成 1%、變成一億、變成五億的時候，會怎麼樣？」
供給端也沒有人打算慢下來。Baker 說：「Anthropic 如果當初在算力上像 OpenAI 那麼激進，他們早就... 」他引用四個月前 Dario 的說法：「他說這真的很難，因為在這種規模下，你買太多算力可能會破產，但買太少你可能會輸。」結果已經看到了：「OpenAI 回到牌桌上，SpaceX 帶著 Grok 4.5 和 Cursor 大舉進場。看完這一輪，從賽局的角度，誰敢在短期內鬆手？特別是如果這些錢可以用營運現金流付的話。」他說這兩家在帕累托前沿上，而且有算力。

持續學習：這趟最大的技術收穫

Patrick 問他這趟有沒有學到什麼跟創新有關、讓他特別興奮或好奇的東西。Baker 說：「這裡好像很多人覺得他們已經很接近解決持續學習和樣本效率學習了。」
如果解決了，訓練需求可能出現一次斷點。「有人跟我說，『我』大概是用 200 億個 token 訓練出來的，而這些模型是用 300 兆個 token 訓練的。如果你可以用 10 兆個 token 訓練一個東西，然後把它放到世界上、讓它有效率地自學，那聽起來對訓練需求不太妙。」
但他自己的結論是這件事的殺傷力有限：「訓練佔半導體算力需求的比例本來就會趨近一個不是零、但很小的數字。」他也不知道時程怎麼演進：「誰知道是長線還是短線。SSI 說他們八月會出模型，有一整個世代的新實驗室在做這件事。」
Patrick 說這對世界是好事，Baker 說：「這對世界會很棒，我們都想要這個。我很難相信這對 AI 基礎設施的需求會是負面的，但我還是想盡量保持開放。」他補充，這些新創輝達全都深度參與。

中國的 DUV

Patrick 說他看到這個消息的反應有兩個極端，一端說這相當於 ASML 在 2001 年的水準，一端說這是全球尖端算力供給敘事的第一大新聞。
Baker 說兩種可能都對。他用飛行器打比方：「DUV 機台像螺旋槳飛機，EUV 像噴射引擎。他們以前沒有，現在據說有了，那可能是一次相變，像從液態變成固態。」然後他把另一半講完：「只是那個螺旋槳飛機落後 25 年。仍然重要，我不認為應該輕視。」
要追上的難度在於過程本身。Patrick 說這是做中學，Baker 同意：「你沒辦法把做的過程加速，你不能瞬間移動到未來，那些學習循環你真的得確實走過一趟。」他認為市場反應過度，理由是時間尺度：「如果這件事真的打到 ASML 的訂單，可能是五年後，那時候市場已經忘記、擔心、忘記、擔心過好幾輪了。」
Baker 對中國的評價沒有打折：「中國真的非常聰明，工作起來狠得不得了，而且他們把這件事視為國家層級。」他對美國人的判斷能力則保留，說身為美國人很難真的搞懂中國正在發生什麼。
他對趨勢的看法是：「我們正在脫鉤，這個過程已經啟動，現在幾乎感覺是兩邊互相強化，這很不幸。但事情就是這樣了，他們不會停，當然我們也不會。」

----

Patrick 問 AI 最壞的情況是什麼。Baker 說：「我認為監管一定是最大的風險，那是最明顯的風險。你就是不能忽略紐約做出資料中心的暫停令。」
他認為問題出在產業自己：「我們活在一個後事實、後邏輯的政治世界。AI 產業的公關做得非常糟。華盛頓的政治敘事，還有很多一般美國人心裡的說法，就是資料中心會抬高你的電費、會把你的水用光，然後把你的工作拿走。」
他說實際談出來的條件正好相反：「以現在談的條件，資料中心進來的時候，周圍所有人的電費一般來說反而會降。以前開發商要做的是給警察局和消防局買新車、新裝備，現在變成我們幫你蓋一間醫院、一所學校、一個新的警察局和消防局，還要把你的電費降下來。」工作的部分他認為被誤解成那些是一次性的：「工作是持續的，因為你需要水電工、電工、空調技師。資料中心在很多層面上是我這輩子看過對藍領工資最好的一件事。」他也指出政治上的錯位，說名義上代表藍領工人的民主黨正在把這些工作拿掉。
錯誤的說法傳得比較快。Baker 引了一句「謊言可以繞地球一圈，真相還沒起床」，然後舉例：「有一位作者在書裡算錯，把資料中心的用水量高估了一萬倍。不是一點點，不是一個數量級，不只兩個三個。她已經承認過很多次，那件事早就被徹底闢謠了。」Patrick 拿了一個八十年前的對照：「就像大力水手效應。卜派吃菠菜的理由，是一本學術書把小數點點錯了兩位。菠菜的鐵含量並沒有比其他東西高，但就是那一個來源傳開了，到現在還有人這樣說也這樣認為。」
他認為產業該講的還有另一組故事，例如今年的 ASCO 是他聽過單一場會議上最多科學突破的一次，其中一定有一部分要歸功於 AI：「如果你有生病的小孩、生病的父母、生病的親人，AI 會實質提高他們康復的機率。」
業內人士的盲點是把常識當成共識。Baker 說：「這裡的人覺得這一切明顯到不行，所以他們沒辦法理解，這是一個真實但跟大多數美國人差距極大的看法。」他說紐約感覺只是第一個，連很挺成長的深紅州也在傳同樣的訊息：你們自己的故事講得不好，別人沒辦法替你們講。

當所有人都把新聞餵給同一個模型

Baker 對市場為什麼會這樣變動，給出一個他自己的解釋。他先提了一個舊框架：「我們之前談過 Michael Mauboussin 的說法，多樣性的崩解是泡沫和崩盤的成因。」
然後是新的現象：「我認識的公開市場投資圈裡，不管散戶還是法人，每一則新聞都馬上被丟進 Claude，有時候是 Claude Code，有時候是一個 Claude agent。它本身是機率性的，但它解讀這些新聞的方式大概不會有太多變異。」他用媒體史做類比：「大家會講媒體的碎片化，說以前 Walter Cronkite 是唯一的真相之聲，現在沒有了。Claude 有點像是股市的 Walter Cronkite，大家就是相信它說的。」他覺得風險是：「它真的很聰明，但它不見得每次都對。而股市本質上處理的是對未來的機率性、貝氏的解讀。」
價格的行為因此變得很極端。Baker 提到一張圖：「有一個叫 TBU 的人，算是匿名半導體黑手黨的一員，他貼了一張日本電容股的圖，說我們在六週內就走完了一整個電容循環。而且是真的。基本面根本還沒出現，你已經走完一個正常來說要三年的循環。」
投資人的行為也被壓縮成同一個動作。他說：「我在富達有個朋友說，過去三年的正確走法就是用最快的速度去做最笨、最表面的那件事，然後在這些事情之間輪動。」Patrick 問現在那件事是什麼，Baker 說：「就是砍風險。整個月都是在對那些除了信貸以外、事實上根本不成立的敘事砍風險。」
他沒有把技術面的警訊當成雜訊。2022 年市場擔心的是衰退、利率和通膨，DeepSeek 和解放日也都很明顯，他說「這些很明顯的東西，在某種奇怪的意義上是會讓人安心的」。這次不一樣：「除了信貸以外，那些具體的說法都有點荒謬。可是它還是在跌。技術派會說這有點可怕。照定義來說，殺死你的是你沒看到的那顆子彈。」接著他說：「投資裡最重要的三個字不是安全邊際，是『我不知道』。」
他也知道自己在光譜的哪裡。Patrick 問他有沒有遇到比他更看多的人，Baker 說：「這裡基本上每個人都比我看更多。」他舉了 Dwarkesh 寫的一段，說租一張 H100 一年要 25 萬美元，大約是現在現貨價的 15 倍：「那不在我原本的機率空間裡，連考慮過但當成極不可能而排除掉的那一區都不曾在。」
他自己的處境是這樣：「我看股市，覺得自己像個愚蠢的樂觀主義者。可是我跟人聊完，不管是實驗室的人還是這個生態系裡的任何人，我又變成像是所有人裡面最看空的那一個。很奇怪。」
回到他這趟的動機，他說：「我想被嚇到。我不想在這些股票越跌越便宜、預期報酬越來越高的時候，覺得自己像個瘋子。」他找到的結果是七月的基本面比六月還要明顯地更好。節目收在這裡：「我們就看這些股票一年後在哪裡。未來是機率性的，但這是一個很令人興奮的時刻。」
