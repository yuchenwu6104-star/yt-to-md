# /fb — 文章 / 網頁轉 Facebook 貼文

由 Claude 直接撰寫，不呼叫外部 API。風格定位：像朋友推薦一篇好文章，把精彩處挑出來說給你聽，看完想去點原文。

## 使用方式

```
/fb <本地 .md 路徑或檔名 | URL>
```

範例：
```
/fb 2026-03-31_yt_GQ_Taiwan_華爾街交易員_理財真相_財務自由.md
/fb https://hackmd.io/@JbhlYkBtRJukuvsXMtL6lg/SJGNn7qibe
```

## 執行流程

### 步驟 1：判斷輸入類型並取得內容

**若輸入含 `http`（URL 模式）：**
- 用 `WebFetch` 工具抓取頁面文字
- `source_link` = 該 URL

**若輸入為本地檔案：**
- 路徑解析規則：
  - 完整路徑直接使用
  - 僅檔名則在 `C:\Users\wukee\OneDrive\文件\Obsidian Vault\投資筆記\每週總結\每日研究` 中查找
- 用 `Read` 工具讀取內容
- 解析 frontmatter，提取 `youtube_url`（作為 `source_link`）、`channel`、`video_title`

### 步驟 2：Claude 撰寫 FB 貼文

按照下方**格式規格**直接撰寫，無需呼叫外部 API。

### 步驟 3：落檔

用 `Write` 工具存至：
`C:\Users\wukee\OneDrive\文件\Obsidian Vault\投資筆記\每週總結\FB文章候選`

檔名：`YYYY-MM-DD_fb_<關鍵字>.md`
（今天日期 + 從標題/URL 提取的關鍵字，最多 60 字元）

落檔後告知：落檔路徑、中文字數。

## 格式規格

**字數：** 800–1000 中文字

**結構：**

1. **開場（1–2 段）**
   - 點出作者 / 來源是誰
   - 這篇文章的核心論點是什麼，為何值得讀
   - 夠有趣才繼續讀

2. **精彩摘要（3–5 段）**
   - 每段聚焦一個有洞察力的論點
   - 具體引用文中的數據、語句、比喻——不要只是概述
   - 讓讀者覺得「哦，這個我不知道」

3. **結尾**
   - 自然收束，可提出一個開放性問題或感想
   - 最後一行：「推薦讀原文。」+ source_link

**格式細節：**
- 段落間空一行
- 不用 `#標題` 分段
- 不用 markdown 語法（無 `**`、無 `-`、無 `##`）
- 不加 hashtag 清單
- 允許極少量 emoji（如文末一個）
